How official MSCI free end-of-day history works (observed this run)
========================================================================
- Entry: https://www.msci.com/ -> Indexes -> Index resources
  "Performance": Analyze returns ... with end of day performance data
  Tool URL: https://www-cdn.msci.com/web/msci/index-tools/end-of-day-index-data-search
  The tool loads in an iframe from: https://app2.msci.com/products/index-data-search/
- Equity Factsheets (free PDF, keyword search, Variant filter Price/Gross/Net):
  https://www-cdn.msci.com/web/msci/index-tools/equity-fact-sheet-search
- Indexes explorer (subset of ~3,932 equity indexes; name/code search, Variant Price):
  https://www.msci.com/indexes

Anonymous vs login:
- Homepage, factsheet search, factsheet PDFs, EOD search, index chart, and "Download Data"
  all worked WITHOUT registration or login in this run.
- No login/sign-up wall was reached. Did not type email or create an account.
- The EOD tool footer says: "For additional historical index data, contact MSCI Client Service."

Price vs TR:
- EOD tool "Index Level" offers Price (selected), Net, Gross (and decrement/risk-control variants).
  Price is price return, not total return / net total return.
- Chart "Download Data" files state "Index Level :,Price" and "Currency :,USD" in the header.
- Do not silently substitute Net/Gross if Price is unavailable for a given listing.

Observed free-history cap (actually tested on CHINA VALUE WEIGHTED, Price, USD, Daily):
- Term "4 Year" keeps Frequency = Daily. Chart/export window observed:
  Start Nov 16, 2022 -> End Nov 16, 2026 (daily).
- Term "5 Year", "Full History", or a custom Start Date earlier than that ~4-year window
  causes the form to switch Frequency to Monthly on Update (Daily does not stick).
- Full History monthly for this index opened Start Jan 31, 1997 -> End Nov 16, 2026
  (file month-ends through Oct 30, 2026). That series INCLUDES pre-launch backtest.
- Export format: historyIndex.xls (Excel), convertible to csv. Columns: Date, index level.
- Factsheets give launch language + period/annual returns (and sometimes only NET tables);
  they are not a daily EOD series.

Important: First Value / base date on a factsheet is NOT the official launch/publish date.
Do not treat pre-launch backtest as live official history.
