- `qdii_candidates.csv`：42 行。候选来自上交所基金简称表和巨潮深市 ETF/LOF 列表，再用天天基金档案的跟踪标的/业绩比较基准确认，并要求页面出现 QDII 或基金类型含「海外」。`avg_amount_60d` 是截至 2026-09-30 的 60 个交易日搜狐日行情 `hq[8]` 的算术平均，换算成人民币元（源字段与成交量×价格对照后按万元理解，原始响应在 `raw/sohu/`）。不足 60 个交易日则留空。
