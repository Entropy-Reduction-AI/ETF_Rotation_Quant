# ETF_Rotation_Quant

A 股主题 ETF 轮动量化研究：基于 37 个主题的日线与指数数据，按预注册规则回测，并只跑一次冻结样本外验证，产出可执行的持仓信号。

Quantitative research on A-share thematic ETF rotation: preregistered rules, backtests and a single frozen out-of-sample test across 37 themes, producing executable position signals.
