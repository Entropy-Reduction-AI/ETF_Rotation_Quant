## §0 一句话

像 FOF 一样分两层：第一层在 A 股、港股、美股三个市场里只持最强的一个，仓位由两条腿各管一半；第二层在选中的市场里取最强的 3 只。强弱不用固定的回看期，而是在 3–250 天铺满 28 把尺子，按每把尺子最近有多响定权重。

## §2 量：每个序列每天算什么

对每个参加排名的序列 i（研究序列和人民币换算按 v4 §3.1），在交易日 t：

1. **尺子**：G = {3, 4, 5, 6, 7, 9, 10, 12, 14, 16, 19, 22, 25, 30, 34, 40, 47, 54, 63, 74, 86, 100, 117, 136, 158, 184, 215, 250}（3–250 天按对数等距取 30 个点、四舍五入去重，共 28 把）。
2. **速度**：v_n(i,t) = Σ（最近 n 个日对数收益 − 同日现金对数收益）÷（σ(i,t) × √n）。σ(i,t) = t 之前 250 个有效日对数收益的标准差（不含 t）。现金按 v3 §3。
3. **响度和权重**：响度 a_n(i,t) = 最近 n 天 |v_n| 的平均；q_n(i,t) = a_n(i,t) 在 i 自己此前全部 a_n 里的分位（只用 t 之前的值，至少 250 个）。权重 w_n = q_n ÷ Σq。任何一把尺子的分位历史不足 250 个时，当天 28 把等权。
4. **三个读数**：
   - 水平 H(i,t) = Σ w_n·v_n；
   - 转负前沿 F(i,t) = v_n < 0 的尺子个数 ÷ 28（不加权）；
   - 长尺子放缓 E(i,t)：60 天以上 8 把尺子的平均速度 ℓ(t)，**连续两个月都在放缓**，即 ℓ(t) > ℓ(t−20) 且 ℓ(t−20) > ℓ(t−40)（t−20 指 20 个交易日之前）。意思是“一波比一波弱”：两波之间长尺子好转一次不算，要连着两次。
5. **参加的条件**：28 把尺子、E 都有定义（约需 291 个有效日收益）。五日无价退出按 v3 §3.3。

## §3 持仓

### 3.1 第一层：选市场、定仓位

每周最后一个交易日 t 决定，下一个交易日收盘成交（v4 §4.5）。只有一路（周），没有多路平均。

- **市场和代表**：A 股 = 沪深300，港股 = 恒生指数，美股 = 标普500。三个代表的读数决定市场层面的一切。大类表沿用 `config/v5/classes.csv`；“其他海外”“商品”不参加第一层（设计期从没进过前列，v5.1 第 1 稿 §3.1 第 4 问）。
- **两条腿**：腿一 = F < 0.5；腿二 = H > 0 或 E。市场 m 的风险仓位 r(m) = 0.5 × [腿一] + 0.5 × [腿二]。
- **资格**：r(m) > 0，且 U-可交易中该市场当天至少有一个可买的容器（v4 §3.2）。
- **选哪一个**：上周持有市场 h 仍有资格时，只有另一个有资格的市场 k 满足 H(k) − H(h) > 1 才换到 k；否则持 h。h 没有资格时，取有资格的市场里 H 最高的。都没有资格，风险仓位为 0。
- **防守**：1 − r 的部分放进国债（10 年）、黄金里 H > 0 且最高的一只（上周持有的仍满足 H > 0 时，另一只要高出 1 才换）；都不满足拿现金。

### 3.2 第二层：在选中的市场里挑 ETF

- 该市场全部参加排名的容器（含宽基）按 H 从高到低排，取 H > 0 的前 3 只，平分 r。不足 3 只的平分给够格的。一只都不够格时，持该市场的代表（U-可交易里代表没有载体的，持该市场 H 最高的可买容器）。
- 同分按容器 id 升序。

### 3.3 单只离场（每天看）

持有的容器从买入后的最高收盘回落 10%（持有期高点按 v3.1 §4.5 的定义），在当天收盘判断：

- **该市场代表的 F < 0.5**（不是市场在共振回落）：卖出这一只，换成该市场里排名在已持有之外、H > 0 的下一只；没有就换成该市场代表（规则同 3.2）。
- **F ≥ 0.5**（市场在共振回落）：当天按 3.1、3.2 重算全部目标持仓，不等周末。

都在下一个交易日收盘成交。被卖出的容器到下一个周度决策日之前不再买回。

### 3.4 新增自由度

① 前沿门槛 0.5；② 长尺子放缓（60 天以上、连续两个 20 个交易日）；③ 噪音带 1；④ 第二层取前 3。两条腿各一半是对称结构，不另算。由结构定、跑前写死：3 天（T+1 和成本）、250 天（一年）、28 把（相邻尺子相关 > 0.9 即可）、分位至少 250 个、10% 离场（E2 诊断里 8–15% 是一片平台）。
