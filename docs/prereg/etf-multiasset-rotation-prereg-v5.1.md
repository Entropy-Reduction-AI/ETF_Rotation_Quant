## §2 规则

| | B0（E2 新口径） | v5.1 |
| --- | --- | --- |
| 排名 | 所有容器一张表，每个回看期取前 N 名 | 同左 |
| 上限 | 无 | 每个大类在一组里最多 ⌈N/2⌉ 名：N = 3 时 2 名，N = 5 时 3 名，N = 8 时 4 名 |
| 被截的名额 | — | 按排名顺延给下一个合格容器（参加排名且跑赢现金）；顺延到底仍不够 N 名，空位拿现金 |
| 仓位、路数、10% 离场、成交、成本、池子 | 按 v4 B0 | 完全相同 |

- **大类**用 v5 已冻结的 `config/v5/classes.csv`（七类：A 股、港股、美股、其他海外、商品、国债、黄金），一个字不改。防守大类同样受上限，但国债、黄金各只有 2 个以内的容器，上限在中国池里不会触发。
- 执行：在 B0 的选取步骤里加上限，其余用 B0 的同一套 `simulate_path` 执行（2026-11-01 引擎裁定的必改项同样适用）。
- **新增自由度**：① 大类划分（v5 已有）；② 上限 ⌈N/2⌉。合计 2 个，在项目上限约 4 个之内。

**为什么是“一半”，不是别的数**（跑之前定，理由只来自结构，不来自收益）：

- 不设上限（= B0）：池子变大以后，前 N 名可能被同一个市场里几乎一样的容器占满。v4 证据：A 股 14 个容器约等于 1.4 个独立选择；T4 往池子里加美股行业后，前五年年化超额少了 8.5 个百分点。
- 上限 1 名：等于每类一个代表，这正是 v5 原版的硬伤 ①、②。
- 一半：最强的市场仍然可以拿到多数名额（先为不可胜，大行情来了要集中），但至少给第二强的市场留一半；N 越大，单一市场能占的比例越低。
