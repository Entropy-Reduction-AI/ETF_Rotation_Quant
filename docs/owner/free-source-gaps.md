## 1. 深交所期权日线缺口

> **159919 从 2019-12-23、159915 和 159922 从 2022-09-19，到 2022-12-11，免费来源没有日线。**

登记日 2026-11-03。票据 #201 C1。状态 `won't-pursue-free`。

库里已有的深交所日线（`data/options/raw/szse/ohlcv/`）这三只都从 **2022-12-12** 起才有行。159901 同日上市，不在这段缺口里。

PR #201 的 `session-coverage.csv` 把这段记成请求窗口内 0 根新 K 线：

| 标的 | 请求起 | 请求止 | 交易日 | 有行 | 缺失 |
| --- | --- | --- | --- | ---: | ---: |
| 159919 | 2019-12-23 | 2022-12-09 | 720 | 0 | 720 |
| 159915 | 2022-09-19 | 2022-12-09 | 55 | 0 | 55 |
| 159922 | 2022-09-19 | 2022-12-09 | 55 | 0 | 55 |

`SCOPE.txt` 把截止写成 2022-12-11。两处都是同一段空洞，没有新的 OHLCV 文件。

已试（#201 `blocked-attempts.csv`；第一轮 `data/options/raw/blocked-attempts.csv` 里已有新浪 null）：

| 来源 | 结果 |
| --- | --- |
| 新浪期权日线 | 合约返回 null。样例 `90000001`、`159919C2001M003700`。第一轮 1295 个深交所合约 id 同样为 null |
| 深交所历史 K 线 | `marketId` 0–59 对期权代码失败。同一接口能给 ETF 159919 |
| 东财 | 连接被关闭，没有 K 线 |
| 腾讯 | ETF 代码可以，期权代码参数错误 |
| 网易、同花顺 | HTTP 502。搜狐称代码不存在 |

## 2. 两所每日结算价

> **上交所、深交所的历史日结算价，免费接口给不出序列。**

登记日 2026-11-03。票据 #201 C2。状态 `won't-pursue-free`。

| 来源 | 结果 |
| --- | --- |
| 上交所云行情 dayk 的 `settlement` | 字段名被接受。截止 2026-09-30 的 844603 根 K 线上非空 0 次。持仓量字段有数，结算价没有。没有写入日结算序列 |
| 上交所当日合约、深交所 `option_drhy` | 只有最新一份快照（结算价 / 前结算价）。日期参数不能把文件滚回历史。快照另存，不能当成到 2026-09-30 的日序列 |
| 深交所风险指标工作簿（第一轮） | 只有希腊字母，没有开高低收、结算价 |

`session-coverage.csv` 里结算价请求窗口全部 0 行：上交所 510050、510300、510500、588000、588080；深交所 159901、159915、159919、159922。深交所当日快照的交易日是 2026-11-03，晚于行情截止日 2026-09-30，只核合约规格。

## 3. 深交所历史持仓量

> **深交所没有日历史持仓，只有当日快照里的合约总持仓。**

登记日 2026-11-03。票据 #201 C2。状态 `won't-pursue-free`。

`option_drhy` 有「合约总持仓」，只对应当日。标的 159901、159915、159919、159922 的请求窗口在覆盖表里都是 0 行。

上交所日持仓已从云行情按标的存放（510050 缺 2015-03-24、2016-03-31 两个交易日，另有 2 个合约 404）。那是另一件事，不标成不再追。
