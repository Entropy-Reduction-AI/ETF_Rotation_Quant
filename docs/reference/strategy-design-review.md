## 什么时候做

每个研究版本的预注册在冻结前必须有一节“设计评审”，由 Orchestrator 写，Reviewer 在冻结前逐条核对。任何一问答不清，不冻结。评审只用规则文字和**信号层面**的描述统计（排名、门槛触发次数、类别成员数、可用数据），不计算任何组合收益；因此不受“结果盲”纪律限制，也不消耗尝试次数。

## 跑前五问

| 问 | 要回答什么 | v5 当时如果问了会看到 |
| --- | --- | --- |
| 1. 钱是否跟着强弱走 | 有没有可能让一个弱品种拿到和最强一样多的钱 | 类里任一只跑赢现金就拿 1/k，和全场最强一样 |
| 2. 挑选发生在哪一层 | 那一层的品种之间差别大不大，独立选择有几个 | 类内挑选（同涨同跌）保留，跨类挑选换成平分 |
| 3. 防守怎么进来 | 一直参与竞争，还是到极端才打开 | 风险类全关才防守；设计期只有 10% 的时间触发 |
| 4. 每个类别、每个开关实际触发几次 | 在设计期信号上数一遍；从没触发的就是空壳 | “其他海外”从没开过，商品 0.2%；五类实际三类 |
| 5. 同结构去掉信号还剩多少 | 先和随机挑选比，再和基准比；对照在预注册里写死 | v5 扣掉“押得少”后和随机差不多 |

第 5 问的对照要在预注册里写死、和策略同一次跑出；其余四问在冻结前用信号统计回答。

## 事前画像

评审的最后一部分是一页“事前画像”，在冻结前写下、冻结后不改，跑完逐条对照：

- **典型持仓**：四种行情（牛市、回调、熊市、反弹）里各大类大约占多少仓位，各举一个设计期里的真实日期。
- **性格**：预计在哪种行情赢、哪种行情输，原因是哪条规则。
- **相对参照**：相对当前最好的一版（现在是 E2 新口径）和随机挑选，年化、回撤大致更高还是更低。

画像写不出来，说明规则还没想清楚。跑完后画像和实际差得越多，越说明对规则的理解有问题，即使结果过关也要在结论里说明。
