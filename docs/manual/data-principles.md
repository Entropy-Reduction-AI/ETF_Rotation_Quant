## 1. 场内 ETF：一律后复权

- 凡是能在场内交易的 ETF（A 股 ETF、QDII、美股 ETF），计算收益一律用**后复权**序列：分红再投资，拆分、合并、份额折算都要处理。
- 这是项目的基石。没有处理好的序列不能进入排名或回测。
- 做法：保留原始收盘价，另存一条后复权序列，两者都登记来源和 SHA256。先确认来源的收盘价有没有已经按拆分调过，避免调两次。
- 每次新增或更新，抽查至少一次分红和一次拆分（如有）前后的收益是否连续。

- **来源优先级**（D19-3）：场内 ETF、LOF 的行情（含后复权）优先用东方财富（例如 akshare 的东财接口，`adjust="hfq"`）；净值用天天基金。腾讯等作为核对来源。LOF 一律取场内交易数据。

## 2. 场外基金：只用来还原市场

- 场外指数基金只用来还原“当年能买到的市场”（D14-1），按单位净值加分红（或累计净值、复权净值）做成收益序列，和其他序列一样参加排名。
- **不考虑**申购费、赎回费、确认天数和到账天数。

## 3. 汇率：缺了就补，并标明是补的

- 先找官方来源（中国人民银行、中国外汇交易中心的公告），接口拿不到就用电脑上网页找。
- 实在找不到时，用最近的已有数据往前平滑补齐（例如取最近 20 个交易日的平均值向前延伸），并在序列上标明哪些日子是补的。
- 港币按人民币计算时，可以用美元兑人民币和港币兑美元换算（港币与美元挂钩是当时已知的事实）。

## 4. 接口拿不到，就想办法

- Grok 团队有自己的电脑。后端接口拿不到的数据，用浏览器去官网、交易所、基金公司或行情网站的页面找，可以下载或手工整理，留下来源网址和截图。
- 付费数据先报给 Orchestrator，由 Owner 决定买不买。

## 5. 一贯的边界

- 设计期可以用今天的知识，不能用今天的数据（D12-8）。
- 不用 2016-01-01 以后的数据计算任何组合收益，除非 Owner 批准一次性检验。
- 不覆盖已有序列；修改要新增一条并写明原因。
