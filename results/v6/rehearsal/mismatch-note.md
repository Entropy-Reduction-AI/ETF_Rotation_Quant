# 唯一的实质差异

检验段判据②（防守平时保费）签收 1.3839 点，预演判据格 2.8290 点，差 1.4451 点。没有为了贴近而改参数，也没有重跑。

原因在接线，不在规则。签收保费是「不设防守 − v6」，两边都是单边 0.2%、每月 60/40（体检 `health.py` 的 `_premium`）。预演判据格把 `SpanBook` 的「不设防守」接成了成本为 0 的前 3 混合（D49 第④块用的那条），所以减数少了成本。同一轮里，预测对账的「防守保费」用的是单边 0.2% 的不设防守，数字是 −1.383910856278514，与签收逐位相同。

其余对照差为 0：检验段回撤、③、④、八条线的年化和回撤（2011–15 与 2006–15）、同结构随机 97.2 百分位和 61.666…% 每月跑赢、预测对账其余四项。
