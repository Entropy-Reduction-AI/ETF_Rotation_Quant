## 日本短端：用这一条

用的是日本银行时间序列检索里的日频无担保隔夜拆借利率平均数，不是政策目标，也不是月平均。

| 项 | 内容 |
| --- | --- |
| 名称 | Call Rate, Uncollateralized Overnight, Average (Daily) |
| 代码 | `FM01'STRDCLUCON` |
| 单位 | percent per annum |
| 入口 | `https://www.stat-search.boj.or.jp/ssi/mtshtml/fm01_d_1_en.html` |
| 检索页上的说明 | Uncollateralized Overnight Call Rate (average)，每个营业日更新，数据集 FM01 |
| 访问 | 匿名 GET 200。序列嵌在这个 HTML 里，没有再要登录 |
| 页面写的起止 | 1998/01/05 至 2026/11/20。页面最后更新 2026/11/25 |
| 解析 | 10547 行日期。其中 7079 行有数值，3468 行是 `NA`。`NA` 里 3012 行落在周六或周日，456 行落在周一至周五 |
| 缺口 | 没有对照日本假期日历。不能把首尾当成没有缺口。平日上的 456 个 `NA` 就是文件里已经标出的缺失，身份未再细分 |
| 覆盖限制 | 序列最后一天是 2026/11/20，早于页面更新日 2026/11/25。周末以 `NA` 出现，所以这不是“只含营业日”的文件 |

`https://www.boj.or.jp/en/statistics/market/short/tonar/index.htm` 返回 404。逐日 xlsx 仍只是单日发布，没有拿来充当完整历史。
