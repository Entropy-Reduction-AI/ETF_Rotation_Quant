## §6.2 过关与尝试次数 · 可算性（仅依正文 + 手工序列）

### §6.2 `candidate_gate`

在**不读取真实 v4 候选 PnL** 的前提下，仅凭正文可实现：

1. 输入：B0 与 T1–T4 的 A 臂日收益 `r_X(t)`、BM-主 `r_B(t)`（上交所日历对齐）。
2. 段内年化超额：按 S1/S2 日期过滤后连乘得 `R_X、R_B`，用同一 `n` 代入 `A_X(S)`。
3. 状态累计：H00300 月末 → `classify_months`；对每个交易日 t，取其所在月的 state，累加 `100×(r_X(t)−r_B(t))` 得 `P_X(状态)`（与 `state_frame` 的 `excess` 按 state 求和等价）。
4. 输出：文中列名与三档 `pass_*` 及总 `pass`。

**缺口：** 仓库内尚无 `candidate_gate()`（计划 v4-R2c）；不影响预注册文本可算性结论。

### §6.3⑤ v4 尝试次数

正文足够实现：分别读两个 ledger → 文件内三元组去重 → 计行 → `L3+L4−C+28+35`，`C` 为两文件中 `arm=C1-shadow` 行数之和。v3 侧现有 `trial_count()` 仅读 v3 文件；v4 须新函数（v4-R2c），与 addendum A3 在「仅 v3 ledger」时应一致。
