## 为什么要在跑之前写死

- **拆法要事先定。** 看过检验段之后再挑拆法，就能把任何结果讲成一个故事。所以下面把拆成哪几块、按哪几段切、怎么读，都在开考前写死。
- **全段一半是设计期。** 2006–15 年是看着数据定规则的十年，年化 15.3%。检验段年化 0% 时，全段年化仍约 7.1%；检验段 5% 时，全段约 9.8%。所以全段的合计数字不能单独引用，也不能拿来判定。
- **全段的用处是看各项来源是否稳定。** 20 年切成四个五年段、20 个自然年，同一项来源在每一段里是正是负，比任何一个合计数更能说明它是结构性的，还是只在设计期出现过。

## 决定

| 编号 | 决定 |
| --- | --- |
| D49-1 | **全段窗口**：2006-01 → 2026-09，与检验段出自同一次从 2006-01 开始的连续运行。**只报告，不出“过 / 不过”，不画判据格。** 判定只看冻结稿 §5：检验段 2016-01 → 2026-09，四条判据全部满足为通过。若冻结代码的检验段口径是 2016-01 重新起步，判定用该口径；连续运行截出的 2016 年以后部分另报，与判定口径的差异写明原因 |
| D49-2 | **分段**：所有拆账和统计一律按五段并列：2006–10、2011–15、2016–20、2021-01 → 2026-09，以及全段；另附逐年（20 个完整自然年 + 2026 年前 9 个月）。报告里全段永远放在分段旁边，不单独出现 |
| D49-3 | **收益拆成六块**（每段、每年都拆，相邻两条序列的年化之差，①–⑥ 六块相加 = v6 净 − BM-主全收益；③ 减去的 BM-同仓位就是 ② 终点的那条价格序列）：①**分红**：BM-主价格 − BM-主全收益；②**仓位差**：BM-同仓位 − BM-主（都用价格）；③**等权倾斜**：同结构等权、不设防守 − BM-同仓位；④**挑选**：前 3、不设防守 − 同结构等权、不设防守；⑤**防守**：v6 毛 − 前 3、不设防守；⑥**成本**：v6 净 − v6 毛。全部按冻结稿 §1.2 每月末 60/40 再平衡（D48-1），候选和母指数用价格指数（附表 A 口径）。⑦**汇率**：美股名额的人民币收益 − 同一名额的美元收益（USDCNY，与预演 `topn_system.py` 同一份），作为美股名额内的一层另报：汇率已经含在人民币价格里，**不进入 ①–⑥ 的和**，也不画进瀑布图 |
| D49-4 | **按名额拆**：③④⑤⑥ 再分 A 股名额、美股名额各报一遍（名额内的值和 × 名额权重后的组合贡献两种，口径同 D47-2）；美股名额另报“前 3 − SPX”（D48-3） |
| D49-5 | **挑选赚的是谁**：逐月记录两个名额入选的候选和下月收益；按候选汇总“入选月数”和“对挑选的贡献”，每段列前 10 名和从未入选的候选，看挑选的钱是否集中在少数几个候选上 |
| D49-6 | **防守赚的是哪几次**：把连续的紧张月份按名额连成“紧张段”，每段报起止月份、股票平均仓位、该段内 v6 − 前 3 不设防守的累计差；另报每个五年段里不紧张月份的累计保费。2008、2011、2015–16、2018、2020、2022 年各次是否触发，如实列出 |
| D49-7 | **全段另报**：八条线的逐日净值和回撤（普通刻度）、年化、最大回撤（写明最深一跌的起止日期，是否跨 2015-12 / 2016-01）、持有 1 / 3 / 5 年的任意起点、四种行情；与体检报告第 3–5 节同法 |
| D49-8 | **事先定的读法**（只描述，不改判定、不改规则）：按下面的顺序判，先符合哪一条就记哪一条：①设计期（2006–15）整段为正，检验段（2016-01 → 2026-09）整段为负或绝对值 < 0.5 点，记“设计期才有”；②否则，四段（最后一段是 2021-01 → 2026-09，不足五年）里**至少三段同号**，并且检验段整段与设计期整段**同号**，记“稳定”；③其余记“不稳定”。报告用这三个标签，不另造说法 |
| D49-9 | **不计新试验**：全段窗口和 D49-3 至 D49-7 都是同一次运行的不同切法，冻结前登记的对照不增不减；看过结果后不再加新的拆法，确需补充的另写 D 编号并注明“看过结果后提出” |

## 二阶、三阶影响

- **对 Dev**：多做 A1、A2 两本账的首尾衔接（设计期 v4 账本 + 检验段 v5 一次性检验账本，接口处逐日核对，不重跑）；现行配置的数据面板接成 2006-01 → 2026-09 连续一条；新增美元口径和逐月入选记录。估计多 0.5–1.5 天。
- **对判定**：无。判定窗口和判据都不变。
- **对上线决定**：拆账给出“v6 的钱从哪来、在检验段还在不在”。若主要来源是仓位差或汇率，说明钱来自“美股放 60%”这件事，可以用更简单的配置拿到；若挑选和防守在检验段仍“稳定”，才说明四步规则本身有用。
- **对以后的版本**：一次性检验报告都按这套分段拆账，全段永远与分段并列。
